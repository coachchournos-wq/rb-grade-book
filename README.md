# Bear River RB Grade Book

Running back play grading app for the Bear River High School athletic department.

- Grade plays 0-3 (with N/A) on Make First Man Miss, Finish Forward, and Blocking
- Ball Security fumble checkmark: each fumble deducts 20% from the overall score
- Playbook memory, game/player/category filters, charts, CSV export, JSON backup
- Data is stored locally in each user's browser (localStorage) - use Setup > Backup to move data between devices

**Live app:** https://coachchournos-wq.github.io/rb-grade-book/

Deployed automatically to GitHub Pages on every push to `main`.
